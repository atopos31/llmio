# 常见问题

## LLMIO 是什么

一个 LLM 网关。它把客户端请求转发到一家或多家的模型服务，提供统一的 API、权重调度、失败重试、协议互转、用量记录和管理界面。

它不是模型，也不代理模型训练。它只负责请求路由、转换和记录。

## 支持哪些协议

客户端：

- OpenAI Chat Completions
- OpenAI Responses
- Anthropic Messages
- Gemini Native

上游：

- OpenAI / 兼容 OpenAI 的服务
- OpenAI Responses
- Anthropic
- Gemini

OpenAI Chat 与 Anthropic 之间可以互转。OpenAI Responses 与 Gemini 只支持同类型上游，不参与互转。

## 支持哪些模型

任何通过上述协议提供聊天能力的模型都可以接入。LLMIO 不内置模型列表，模型由「提供商 + 关联」配置决定。

## 支持 embeddings、音频、文件接口吗

当前对外路由只有聊天类端点：Chat Completions、Responses、Messages、Gemini generateContent，以及 Anthropic Token 计数。

没有 embeddings、audio、files、batches 等端点。

## 会不会保存请求内容

取决于调用方使用的 AuthKey：

- AuthKey 开启「记录 IO」：保存请求体；成功请求还保存响应体。
- AuthKey 关闭「记录 IO」：只保存日志元数据。
- 直接使用 `TOKEN`：不记录 IO。

失败尝试可能保存请求体，但不保存响应体。

## 数据存在哪里

默认在 `./db/llmio.db`（SQLite）。配额配置在 `./db/quota.config.json`。两者都在 `db` 目录。

容器部署时，这个目录通常挂载到宿主机的 `./db`。删除容器不会删除数据。

## 可以用 MySQL 或 PostgreSQL 吗

当前只支持 SQLite。代码使用纯 Go 驱动，不需要额外安装数据库服务。

## 可以启动多个实例吗

不建议。SQLite 只有一个写入者，多个实例共用同一个 `db` 目录会互相阻塞，可能出现 `database is locked`。

需要水平扩展时，需要改造存储层，当前版本不提供。

## 如何修改登录令牌

修改环境变量 `TOKEN`，重启进程或容器。

```bash
docker compose down
docker compose up -d
```

修改后旧令牌立即失效。

## 忘记令牌怎么办

查看部署配置中的 `TOKEN` 环境变量。没有可视化找回入口。

## 是否内置限流

网关不提供全局限流中间件。请求速率由调用方、反向代理或上游限制决定。

网关对上游 429 的处理是：降低该关联的调度权重或移到队尾，并继续消耗重试次数。

## 重试次数是什么意思

「重试次数限制」是一次请求最多尝试多少次，包含第一次。

- 设为 1：只尝试一次。
- 设为 3：最多尝试三次。

每次尝试可能落在不同关联上。开启备用关联时，主池清空后由备用池接管。

## 权重需要加起来等于 100 吗

不需要。权重是相对比例。3:2:1 与 30:20:10 的效果相同。

## Rotor 会按权重轮转吗

当前实现不会在成功时轮转。

Rotor 按权重从大到小排序，每次取队首。成功时队首保持不动；只有 429 才移到队尾；其他失败删除。因此只要队首持续成功，请求就会一直落在它上面。

需要按权重比例分散流量时，请使用 Lottery。

## 为什么请求总是发往同一家

按以下顺序检查：

1. 策略是否为 Rotor。Rotor 成功时不轮转。
2. 是否只有一条启用的关联。
3. 其他关联是否被能力过滤排除。
4. 其他关联是否被熔断。
5. 「优先匹配相同协议」是否只留下了同协议提供商。

## 熔断什么时候触发

开启熔断后：

- 累计 5 次失败进入 Open，冷却 60 秒。Closed 状态下的成功不会清零失败计数。
- 冷却结束进入 HalfOpen。
- HalfOpen 连续 2 次成功恢复 Closed。
- HalfOpen 任意一次失败重新 Open。

429 也会计入失败次数。

熔断状态在进程内保存，重启后清空。

## 备用关联什么时候生效

只有当主关联在本请求内全部被移出候选池后，备用池才接管。

如果主关联一直返回 429，它们只降权、不移出，所以备用池不会接管；重试次数用尽后返回最后一次 429。

## 协议互转会不会丢参数

分三种处理：

- 无法表达且调用方能从响应发现差异：拒绝这次尝试，换下一家。
- 有损但可以继续：转换继续，日志记录短码。
- 纯结构重排：内容不变，不记录短码。

具体短码见[协议互转](Protocol-Bridge)。

## 为什么 Anthropic 上游的回复被截断了

客户端没有提供 `max_tokens` 时，互转层会补 8192。输出超过该值会被上游截断。

在请求中显式设置 `max_tokens`，并确认上游模型支持该上限。

## 为什么设置了价格但没有费用

检查：

1. 关联的三档价格是否填写。
2. 请求是否使用了该关联。
3. 日志是否记录了 Token。
4. 是否只看了旧日志；新价格只影响新请求。

价格为 0 或留空时，费用按 0 计算。

## 为什么分析页的成本合计不对

分析页使用一个币种作为展示单位。如果同一时间窗混用多种币种，合计值没有换算意义。

先用筛选条件限定到同一币种，再比较成本。

## 为什么日志里一次请求有多条记录

每次失败的尝试都会写一条错误记录，最终结果再写一条正式记录。它们的 TraceID 相同。

按 TraceID 搜索可以看到完整的尝试过程。

## 为什么日志一直显示「运行中」

进程异常退出时，未完成的日志会停在运行中。重启后会自动收尾为错误。

如果重启后仍然存在，检查日志写入是否持续失败。

## 删除模型会删除关联吗

不会。删除模型只删除模型本身，关联仍留在数据库中。

删除提供商会同时删除该提供商下的关联。

删除前建议先清理关联，避免遗留记录。

## 可以不用 AuthKey 吗

可以。直接使用 `TOKEN` 调用，拥有全部模型权限。

但 `TOKEN` 不记录 IO，也不适合分发给多个调用方。生产环境建议为每个项目创建独立 AuthKey。

## 支持 HTTPS 吗

LLMIO 自身只提供 HTTP。HTTPS 由反向代理终止，例如 Nginx、Caddy 或云负载均衡。

## 支持 Cloudflare 吗

可以，但必须确认 Cloudflare 没有缓冲 `text/event-stream`。流式响应被缓冲时，客户端会看到整段输出一次性到达。

必要时为流式路径关闭缓冲或使用不缓冲的代理。

## 数据库文件可以手工编辑吗

不建议。配置可以通过控制台或管理接口修改。直接改数据库可能破坏压缩帧、索引或状态字段。

需要迁移或备份时，停止服务后复制整个 `db` 目录。

## 分析页为什么加载慢

分析页一次扫描整个时间窗。日志行数越多、时间范围越宽，耗时越长。在 100m CPU / 128Mi 内存的 Sealos 实例上，约 7.8 万条日志加载约 22 秒。

处理方式：

1. 缩小时间范围。
2. 增加提供商、模型、密钥等筛选条件。
3. 给容器分配更多 CPU。
4. 不需要立即看结果时，使用页面上的取消按钮。

取数已改为流式，内存占用与窗口行数解耦；延迟仍主要取决于扫描行数与 CPU。
